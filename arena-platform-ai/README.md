# ArenaFlow — AI Build Package

ArenaFlow is a web + mobile tournament operations platform. V1 is badminton-first, while the architecture is multi-sport-ready.

## Recommended stack
- Web: Next.js + TypeScript
- Mobile: Expo + React Native + TypeScript
- Backend: Supabase/PostgreSQL/Auth/Realtime/Storage
- State/data: TanStack Query + Zustand
- Validation: Zod
- Monorepo: Turborepo
- Web styling: Tailwind CSS
- Mobile styling: NativeWind

## How to use this package
1. Give the entire `arena-flow-ai-build` folder to Codex/Antigravity.
2. Tell the agent to read `00_MASTER_INSTRUCTIONS.md` first.
3. Ask it to execute only the next development phase.
4. Require tests and a verification report before moving forward.
5. Never ask the agent to build everything in one shot.

## Product naming
Working product name: **ArenaFlow**
Tagline: **Run tournaments. Track every point.**
V1 sport: Badminton
Future sports: Tennis, table tennis, volleyball, football, basketball, cricket, etc.

The brand is intentionally sport-neutral so the product can expand beyond badminton.
