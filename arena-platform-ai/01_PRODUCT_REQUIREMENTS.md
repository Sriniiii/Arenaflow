# Product Requirements

## Vision
ArenaFlow makes tournament operations simple from registration through final result.

## Core workflow
Create tournament → configure categories → register participants → generate draw → schedule courts → run matches → live score → finalize results → update bracket/standings/statistics → publish results.

## User roles
- Platform Admin
- Organizer
- Tournament Admin
- Scorer/Referee
- Player
- Spectator

## V1 badminton capabilities
- Men's Singles
- Women's Singles
- Men's Doubles
- Women's Doubles
- Mixed Doubles
- Knockout
- Round robin
- Group + knockout
- Best-of-3 badminton match scoring
- Live scoring
- Undo/correction
- Brackets
- Standings
- Scheduling
- Courts
- Public tournament pages
- Player profiles
- Match history
- Tournament statistics
- QR sharing

## V1 non-goals
Do not build football, cricket, basketball, volleyball, tennis, payments, social feeds, AI analysis, livestreaming, or marketplace features in the first release.

## Success criterion
A real organizer should be able to run a small 8–32 participant badminton tournament without spreadsheets for core tournament operations.
