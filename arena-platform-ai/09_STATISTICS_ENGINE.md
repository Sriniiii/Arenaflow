# Statistics Engine

## Match statistics
- matches played
- wins
- losses
- win percentage
- games won/lost
- points won/lost

## Tournament statistics
- total participants
- matches scheduled
- matches live
- matches completed
- category counts
- court utilization
- completed games
- points scored

## Round robin standings
At minimum:
played, wins, losses, games won, games lost, game difference, points won, points lost, point difference, rank.

Statistics should be derived from authoritative match/game/event data or maintained through safe transactional updates. Avoid duplicated sources of truth.
